项目名称统一为“朝夕 / Zhaoxi”，文档展示形象为蓝色礼裙。该图用于项目介绍；0.2.31 的现有发布附件仍保留原构建内容，完整礼裙角色包尚未包含在公开下载中。已有角色包可通过“设置 → 外观 → 我的桌宠 → 新建 → 导入角色包”添加。

本版恢复纯每日时间轴，移除日/周切换入口和周视图实例。前后导航固定为前一天/后一天；保留今天、回到现在、分类、重复规则、单日例外、提醒、待办关联及冲突检查，不转换或删除日程数据。

相较 GitHub 上的 0.1.12，本版还包含每日安排和待办管理、可授权的 Apple 提醒事项同步、播报模板、百炼/MiniMax 云语音、添加我的声音向导、API 状态提示、跟随 Codex 启停及中英文界面改进。

发布整理修复了旧文档的“完全不上传”表述，更新插件版本与名称，并补齐跟随辅助程序、图标和嵌套签名。发布构建仅从应用包中加载内置猫咪资源，避免携带开发机绝对路径。

自动测试使用临时数据和模拟服务，不执行真实语音上传或付费请求。可选私人素材检查未包含在公共测试条件内。macOS 权限交互、真实注销/重登、VoiceOver、多屏及 Intel 真机行为尚需独立验收。

构建依据与具体工具链见附件 `BUILD-INFO.json`；下载后通过 `SHA256SUMS` 校验。此测试包不等同于经过 Developer ID 签名及 Apple 公证的正式发行版。
