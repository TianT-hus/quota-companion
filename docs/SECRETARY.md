# 朝夕 · 每日安排与待办

适用于朝夕 0.2.31（build 47）。蓝色礼裙是项目展示桌宠；日程、待办与提醒的使用方式不依赖选择哪一种桌宠。

## 查看每天的安排

从桌宠右键菜单打开“今日安排”。页面显示选中日期的单日时间轴，左右按钮分别切换前一天和后一天；“今天”和“回到现在”帮助返回当前日期与时间。

0.2.31 已移除日/周视图切换。每周重复规则仍可用于创建和编辑安排，已有的周模板、单日例外、分类及提醒不会因此删除或转换。

## 创建、编辑与分类

可以手动新增安排，或粘贴时间表后逐行识别、核对和保存。例如：

```text
工作日 09:00–11:00 整理资料
每天 12:00–13:00 午餐与休息
周末 15:00–16:00 阅读
```

确认日期、开始和结束时间、重复范围及分类后保存。跨午夜的事项需分段；同一天的重叠区间会进行冲突检查。修改前核对影响范围，是选中日期的例外还是重复模板。分类与筛选用于整理和查看安排，不等同于删除被筛掉的事项。

## 待办与 Apple 提醒事项

本地待办可以独立保存，也可关联日程时段；到点不会自动标记完成。删除日程与删除待办是不同操作，关联关系应在确认界面核对。

如果需要 Apple 提醒事项同步，先在应用中授权，再选择要连接的列表。所选列表支持双向操作，并可能通过系统账户同步到 iCloud 或其他服务。普通本地待办不会仅因打开朝夕而自动上传。

## 提醒与语音

可在设置中管理日程提醒和语音播报。系统声音与云语音有不同的数据路径；启用云语音后，实际播报内容可能包含事项标题和时间，并会发送给所选服务商。详见 [声音使用指南](my-voice-guide.md) 和 [隐私说明](PRIVACY.md)。

日程和配置采用本地持久化及迁移机制。不要手动替换数据文件，也不要把真实日程、账户信息或完整日志粘贴到公开 issue。
