# 排错与限制

| 现象 | 检查 |
| --- | --- |
| 没有额度 | 检查自己的 Codex 登录、CLI 路径和网络；应用不会虚构缺失窗口 |
| 显示缓存/离线 | 上次数据保留但并非实时。恢复网络后等自动重连或点刷新 |
| 只显示周额度 | 服务器可能只返回一个窗口；不会补造 5 小时额度 |
| 自定义 CLI 不生效 | 填写可执行文件路径，点击刷新。路径无效会继续搜索默认位置 |
| 插件工具找不到 | 先构建或安装 app，再添加随包市场、安装插件、开启新会话 |
| helper 找不到 | 源码树没有预编译 helper；使用随包市场或 Release 的 PluginMarketplace |
| 自定义路径用户的插件离线 | 先启动 app，使 helper 经 app 的 socket 读取 |
| 导入角色失败 | 按角色包规范检查尺寸、alpha、文件大小、填充边界；失败保留原选择 |
| 图片缺失 | 恢复内置猫咪；不会删除已有用户原图 |
| macOS 阻止打开 | 确认来源与 SHA256；当前 ad-hoc 包非公证发行，不保证下载首启 |
| 原生测试无屏幕/HEIC 失败 | 需要登录的图形会话及系统媒体服务，不能用无窗口沙箱结果代替真机验证 |

已知边界：只处理主 `codex` 桶，不含 Spark 等独立桶、账单或额度购买。无跨设备同步、手机端或自动更新。MCP 内联卡片取决于宿主支持。CLI/App Server 协议可能变化；没有数据时界面会提示在本机 Codex 登录并检查 CLI 路径和网络，未提供内置登录流程。永久不响应的 CLI 可能造成等待，恢复时可以退出并重新打开 app；不要把诊断输出直接公开。
