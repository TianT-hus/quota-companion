# 朝夕 · 语音与“添加我的声音”

适用于朝夕 0.2.31（build 47）。蓝色礼裙是项目展示形象，语音来源与桌宠外观分别设置。朝夕支持系统声音，以及用户主动配置的百炼或 MiniMax 云语音。

## 配置平台

在“设置 → 语音”中选择受支持的平台接口并保存 API Key。密钥保存在 macOS 钥匙串；请直接在应用的配置界面输入，不要发到聊天、公开 issue 或配置截图中。

“测试 API 连接”会实际请求所选平台。系统可能要求批准钥匙串访问；状态提示用于区分待授权、可用或失败，点击状态入口可查看当前结果。服务价格、账户条件和远端数据保留规则以所选平台的当前说明为准。

## 添加自己的声音

1. **选择平台**：打开“添加我的声音”，选择百炼或 MiniMax；未配置时先完成平台账户配置。
2. **准备声音**：选择本地录音或导入音频。首次主动录音时才申请麦克风权限；在应用提示的时长和大小范围内准备单人、清晰的样本。
3. **检查并创建**：回听样本、填写名称，确认声音使用授权、音频上传与可能产生的费用，再提交创建。
4. **试听效果**：根据向导提示生成试听。远端建声或试听可能收费；不要因等待或失败连续重复提交。
5. **用于日常播报**：验证后选择使用该声音，或暂不切换。日程与额度语音提醒是否开启，以各自设置为准。

本地检查能发现格式、时长、体积和明显静音问题，不能保证服务商接受样本或复刻质量。遇到“结果待确认”时，先从声音管理入口查询现有操作状态。

## 管理与隐私

“管理我的声音”提供查询、试听、改名、使用和删除等操作。删除远端声音需要确认，可能影响同一服务商账户下对该声音的其他使用；删除前先检查当前播报选择。

完成或放弃向导会清理本次临时材料；主动导出的录音和原始导入文件由用户自行保留。关闭本地向导不等于撤回服务商已收到的音频。云语音会发送实际播报文本，声音克隆会在确认后上传音频；详见 [朝夕隐私说明](PRIVACY.md)。
